## 🌟 نظرة عامة (Executive Overview)

**نظام دراجون ستور (Dragon Store ERP)** هو نظام برمجي مؤسسي متكامل تم تصميمه وبناؤه خصيصاً لتلبية احتياجات الشركات ومتاجر الإلكترونيات والأنظمة الأمنية، ومراكز الخدمات الفنية وحلول البرمجيات. يتميز النظام بالقدرة على إدارة وحدتي أعمال متزامنتين (Dual Business Units):
1. **وحدة المتجر التجاري والأنظمة الأمنية والشبكات (Shop & Security Systems)**.
2. **وحدة البرمجيات والحلول السحابية والخدمات الرقمية (Software & Digital Solutions)**.

النظام مبني على قاعدة بيانات **MySQL** قوية وسريعة الاستجابة، مع واجهة مستخدم فائقة العصرية تدعم الوضعين الليلي والنهاري (Dark / Light Mode) ومصممة بالكامل وفق تجربة المستخدم العربية الفائقة (RTL First-Class Support).

## 🚀 الإمكانيات الجبارة والمميزات الفريدة (Key Capabilities)

### 1. مصفوفة الصلاحيات الدقيقة وعزل الخزائن والمخازن (Granular Matrix RBAC)
* **تحكم دقيق لكل مستخدم على حدة:** إمكانية تخصيص الصلاحيات بدقة متناهية لكل موظف بشكل مستقل.
* **مصفوفة الأذونات الستة لكل شاشة:**
  $$\text{[ عرض | إضافة | تعديل | حذف | طباعة | تصدير ]}$$
* **عزل وتقييد الخزائن (Treasury Isolation):**
  * إمكانية تخصيص خزينة محددة لكل مستخدم، مع **حجب أرصدة ومعاملات وكشوف باقي الخزائن تماماً** لمنع الاطلاع على سيولة المؤسسة والحفاظ على سرية الإيرادات.
* **عزل وتقييد المخازن (Warehouse Isolation):**
  * إمكانية ربط الكاشير أو البائع بمخزن محدد، بحيث يُقفل عليه نظام البيع (POS) ولا يمكنه البيع أو الخصم إلا من مخزنه المصرح به، مع حجب حركات المخازن الأخرى.
* **مصفوفة العمليات المالية المخصصة:**
  * تحديد دقيق لمن يحق له: الإيداع، السحب وصرف المصروفات، التحويل بين الخزائن، تحصيل دفعات العملاء، سداد فواتير الموردين، وصرف سلف الموظفين.
* **حماية الخصوصية ولوحة الهبوط الآمنة (Minimal Dashboard View):**
  * في حال عدم امتلاك المستخدم لصلاحية عرض لوحة المؤشرات المالية الرئيسية، يوفر النظام شاشة هبوط بديلة أنيقة تحتوي على شعار وهوية البرنامج واسم المستخدم فقط دون الكشف عن أرقام الأرباح أو المؤشرات الحساسة.
* **الإخفاء الآلي من القائمة الجانبية (Smart Sidebar Visibility):**
  * تختفي الصفحات والمجموعات غير المصرح بها بالكامل وتلقائياً من القائمة الجانبية.

---

### 2. محرك نقاط البيع والمبيعات الفوري (Next-Gen POS & Sales Engine)
* **واجهة كاشير سريعة واستثنائية:** دعم العمل السريع بالفأرة أو عبر لوحة المفاتيح والماسحات الضوئية للباركود.
* **توليد وقراءة الباركود:** دعم قراءة وتوليد باركود دولي ومحلي متوافق مع معايير EAN-13 مع إمكانية طباعة ملصقات الباركود.
* **تعليق واستئناف الفواتير (Hold / Suspend Invoices):** حفظ سلة العميل مؤقتاً لخدمة عميل آخر والعودة لها بضغطة زر واحدة.
* **طرق دفع متعددة ومرنة:**
  * دفع نقدي (Cash).
  * محافظ إلكترونية (Vodafone Cash, Orange, etc.).
  * شبكة المدفوعات اللحظية إنستاباي (InstaPay).
  * الدفع الآجل على الحساب وتتبع مديونية العميل (Credit).
  * **تقسيم الدفع (Split Payment):** إمكانية تجزئة الفاتورة الواحدة بين جزء كاش وجزء إلكتروني بنكي بدقة متناهية.
* **عروض الأسعار الرسمية (Quotations):** إصدار عروض أسعار بتصميم رسمي واحترافي مع إمكانية تحويلها إلى فواتير بيع فعلية بنقرة واحدة.
* **حساب الخصومات وهامش الربح المباشر:** احتساب هامش الربح الإجمالي (Gross Profit) ونسب الأرباح لكل فاتورة فورياً.

---

### 3. إدارة المخازن المتعددة وحركة المخزون (Inventory & Multi-Warehouse)
* **إدارة متعددة للمخازن والفروع:** فتح مخازن رئيسية، مخازن فرعية، ومخازن سيارات التوزيع مع معرفة جرد كل مخزن.
* **تتبع حركات المخزون المتكاملة:**
  * أذون استلام بضائع من الموردين (Stock In).
  * أذون ارتجاع بضائع للموردين (Stock Return).
  * مناقلات وتحويلات دقيقة بين المخازن (Stock Transfer).
* **إدارة التصنيفات والباركود:** تصنيف هرمي للمنتجات مع إمكانية رفع الصور وضغطها تلقائياً.
* **تعدد أنواع الأصناف:**
  * سلع مادية ذات رصيد ومخزون (Physical Goods).
  * خدمات وأعمال فنية وصيانة (Services).
  * منتجات رقمية وتراخيص برمجية (Digital & Software).
* **تنبيهات النواقص والحد الأدنى:** تنبيهات فورية عند وصول أي صنف لحد الطلب الحرج (Reorder Point).

---

### 4. الإدارة المالية والخزائن ومراقبة السيولة (Treasury & Cash Management)
* **تعدد الخزائن والحسابات:** إدارة الخزائن النقدية، الحسابات البنكية، والمحافظ الإلكترونية مع أرصدة حية ومحدثة لحظياً.
* **كشوف حساب تفصيلية:** استخراج ومطابقة حركة كل حساب أو خزينة مع فلاتر الفترات الزمنية المتقدمة.
* **إدارة المصروفات التشغيلية:** تبويب وتوثيق مصروفات الإيجارات، الفواتير، والتشغيل اليومي مع التحقق الصارم من كفاية الرصيد.
* **التحويلات والمناقلات الداخلية:** نقل وتغذية السيولة بين الحسابات والخزائن مع قيود إثبات تلقائية.

---

### 5. إدارة العملاء والموردين والموظفين (CRM & HRM)
* **دليل العملاء والمديونيات:** تسجيل بيانات العملاء، تصنيفهم (جملة / قطاعي)، تحديد حدود الائتمان، ومتابعة كشف الحساب والمديونيات القديمة.
* **دليل الموردين والمستحقات:** توثيق الموردين، شروط الدفع، فواتير الشراء، ومواعيد السداد.
* **إدارة مسيرات ورواتب الموظفين:**
  * تسجيل بيانات الموظفين، الرواتب الأساسية، العمولات، ومسيرات الرواتب.
  * نظام صرف السلف ومسحوبات الموظفين مع فحص الرصيد والحد الأقصى للراتب تلقائياً ومنع تجاوزه.

---

### 6. التقارير والتحليلات المحاسبية المتقدمة (Real-Time Analytical Engine)
* **قائمة الأرباح والخسائر الشاملة (P&L Report):** صافي المبيعات، تكلفة البضاعة المباعة (COGS)، مجمل الربح، المصروفات، وصافي الربح التشغيلي.
* **تقارير المبيعات والأرباح:** تحليل المبيعات حسب الصنف، التصنيف، الفترة، وطريقة الدفع.
* **تقارير تقييم المخزون والنواقص:** إجمالي قيمة البضاعة بسعر الشراء وسعر البيع، والأصناف الراكدة والأكثر مبيعاً.
* **تقارير أرصدة العملاء والديون المعدومة.**
* **تقارير مستحقات وأرصدة الموردين.**
* **تقارير حركات الخزائن والسيولة وسجل الحركات الرقابي (Audit Log).**

---

### 7. الطباعة والتصدير الاحترافي (Print & Export Engine)
* **طباعة الفواتير الحرارية (POS Thermal Receipts):** دعم مقاسات 80mm و 58mm مع الباركود وتنسيق مالي احترافي.
* **طباعة فواتير وعروض أسعار A4 / A5:** قوالب فواتير ضريبية ورسمية تحتوي على هوية الشركة والشعار والحسابات البنكية.
* **التصدير الفوري:** إمكانية تصدير كافة الجداول والتقارير المالية والمخزنية بضغطة زر إلى:
  * **ملفات إكسيل Excel (.xlsx)** منسقة باللغة العربية.
  * **ملفات PDF جاهزة للطباعة والمشاركة**.

---

### 8. نظام الترخيص والحماية المشفر (Hardware-Locked Licensing Shield)
* **تشفير كامل لملف الترخيص (AES-256):** تشفير محلي قوي لملف `Dragon.enc`.
* **ربط عتادي صارم (Hardware ID - HWID):** ربط الترخيص بالرقم التسلسلي للوحة الأم والقرص الصلب للجهاز، مما يمنع نسخ أو نقل البرنامج لجهاز آخر دون ترخيص.
* **تشفير وحماية الكود البرمجي (Code Obfuscation):** حماية ملفات التفعيل والترخيص بخوارزميات تشويش الكود المتقدمة (Control Flow Flattening & RC4 String Encryption).
* **تفعيل سحابي مباشر:** إمكانية التحقق والتفعيل التلقائي والتجديد عبر السيرفر السحابي بضغطة زر واحدة.

| **الواجهة الأمامية (Frontend)** | React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Vite 8 |

## 💻 متطلبات التشغيل (System Requirements)

* **نظام التشغيل:** Windows 10 / Windows 11 / Windows Server (64-bit).
* **بيئة التشغيل:** Node.js v18.0 أو أحدث.
* **قاعدة البيانات:** MySQL Server 8.0+ أو حزمة XAMPP / WampServer.
* **الذاكرة العشوائية (RAM):** 4 جيجابايت كحد أدنى (يوصى بـ 8 جيجابايت).
* **المعالج:** معالج ثنائي النواة 2.0 GHz كحد أدنى.

## ⚙️ التثبيت والتشغيل المحلي (Setup & Installation)

### 1. استنساخ المشروع وتثبيت الحزم:
```bash
# تثبيت الحزم والمكتبات
npm install
```

### 2. إعداد قاعدة البيانات:
* تأكد من تشغيل خادم MySQL (عبر XAMPP أو خدمة Windows).
* قم بإنشاء قاعدة بيانات جديدة باسم `dragon_erp_production` أو استخدم معالج التثبيت التفاعلي المدمج في النظام.

### 3. تشغيل النظام:
```bash
# تشغيل بيئة التطوير المباشرة (الخادم والواجهة)
npm run dev

# أو بدء الخادم في وضع الإنتاج
npm run start
```
* افتح المتصفح على العنوان: `http://localhost:3000`
